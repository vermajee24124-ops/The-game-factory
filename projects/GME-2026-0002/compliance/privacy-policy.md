# Privacy Policy: Pocket Board 3D

**Version:** 1.0.0

Pocket Board 3D is designed as an offline game.

## Data collection

The base game does not request an account, login, backend service, analytics SDK, advertising SDK, or in-app purchase SDK. The base game does not intentionally transmit gameplay or personal data over the network.

## Local data

The game may store local gameplay progress, such as a best score and round information, on the device using the platform's application data area. This information is used only to restore the local game state.

## Permissions

The base build is designed to request no runtime device permissions.

## Changes

If future releases add online services, analytics, advertising, accounts, or purchases, this policy must be revised and the store disclosures must be re-audited before release.

## Contact

Use the support contact published with the store listing for questions about a released build.
