## Curation rule

The full source archives are not copied wholesale into the runtime project. Only selected, compatible assets should be integrated after import validation, mobile sizing/compression, collision review, and visual consistency review.

## Current implementation

The game currently remains build-safe without depending on unverified binary assets. The studio upgrade has improved procedural environment composition, vehicle presentation, lighting/fog, camera feedback, and track readability.

The supplied asset library remains the approved source library for the next curated asset-import pass.
