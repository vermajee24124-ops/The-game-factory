# Turbo Rush Release Status

## Integrated core
- Godot 4.7.2 pinned
- Offline-first finite racing loop
- Deterministic procedural level generation
- 1 player + 5 AI
- Traffic, obstacles, coins, diamonds and boost
- Local save with backup/checksum
- Progression, rewards, cars, paints and wheels
- Basic landscape UI and touch controls
- Automated 10,000-level generation smoke coverage

## Release blockers
- Native production ad SDK adapter
- Native Aptoide billing adapter
- Purchase receipt/server validation required by the selected store
- Production consent/ATT/privacy flows where required
- Production art/audio/VFX
- Device-matrix performance profiling
- Final store compliance audit
- Final Android/iOS release builds

A release candidate must not be labeled production-ready until these gates pass.
