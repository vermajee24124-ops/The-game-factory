Godot ही LLM और AI एजेंट्स के लिए सबसे सटीक क्यों है?

    1. टेक्स्ट-आधारित फाइल आर्किटेक्चर (Text-based Scenes): Godot में हर सीन (.tscn) और रिसोर्स (.tres) प्लेन-टेक्स्ट (YAML जैसी रीडेबल फाइल) होते हैं।
       किसी भी LLM को नया सीन बनाने, नोड्स जोड़ने, या कै रेक्टर की प्रॉपर्टीज सेट करने के लिए बाइनरी फाइल की जरूरत नहीं होती; वह सीधे कोड लिखकर सीन जनरेट कर सकता
       है।
    2. GDScript (LLMs के लिए सबसे आसान भाषा): Godot की प्राथमिक भाषा GDScript है, जो सिंटैक्स में Python जैसी है। मॉडर्न LLMs (Gemini, Claude, GPT)
       GDScript में बिना बग के बहुत सटीक कोड लिखते हैं, जबकि C++ या Rust में एजेंट अक्सर मेमोरी और कं पाइलेशन एरर में फं स जाते हैं।

    3. हेडलेस और CLI सपोर्ट (Autonomous Agent Loop): Godot को बिना किसी GUI विंडो के बैकग्राउंड में चलाया जा सकता है (godot --headless)। इसका
       मतलब है कि आपका AI एजेंट कोड लिखकर कमांड लाइन से गेम को रन कर सकता है, एरर लॉग्स पढ़ सकता है और खुद को सुधार (self-debug) सकता है।
    4. स्टूडियो-लेवल ग्राफिक्स और क्षमताएं: Godot 4 में आधुनिक Vulkan रेंडरर, SDFGI (ग्लोबल इल्यूमिनेशन), वॉल्यूमेट्रिक फॉग, एडवांस शैडर्स और बेहद ताकतवर 2D/3D
       नोड सिस्टम मौजूद है, जिससे कमर्शियल और इंडी-स्टूडियो स्तर के गेम्स बनाए जा सकते हैं।

               │
               ▼

     ├── Agent 1: Game Designer (गेम मैके निक्स और लेवल प्लान)
     ├── Agent 2: Programmer (GDScript कोड जनरेशन)
     ├── Agent 3: Scene Builder (.tscn फाइलें और नोड ट्री)
     └── Agent 4: Tester/Debugger (Godot CLI / MCP टूल कॉलिंग)
               │
               ▼
[ Godot Engine Project ]                ─── (Debug Logs / Errors) ───► Agent Self-Correction
इसे शुरू करने के 2 सबसे असरदार तरीके :

       Godot MCP (Model Context Protocol): Godot का ओपन-सोर्स MCP सर्वर (godot-mcp या Godot AI) इंस्टॉल करें। यह आपके AI एजेंट (जैसे Claude
       Code या Cursor) को सीधे गोडोट प्रोजेक्ट के अंदर नोड्स बनाने, स्क्रिप्ट अटैच करने और गेम टेस्ट करने के टूल्स (API endpoints) देता है।

       कस्टम Python एजेंट + Subprocess: Python में एक एजेंट स्क्रिप्ट बनाएं जो LLM API (OpenAI, Gemini, या Anthropic) को कॉल करके .gd और .tscn फाइलें
       राइट करे, और फिर subprocess.run(["godot", "--path", "./project", "--headless"]) चलाकर कं सोल आउटपुट एजेंट को फीडबैक के
       रूप में वापस दे।

   2. Ponytail प्लगइन:

              सामान्य कोडिंग एजेंट अक्सर ओवर-इंजीनियरिंग करते हैं (जैसे साधारण स्वाइप डिटेक्शन के लिए 400 लाइनों का कस्टम जेस्चर इंजन बनाना)।

चरण 4: CPU-First हेडलेस वेरिफिके शन लूप (Zero GPU Dependency)
क्योंकि आप इसे GitHub Codespaces, Modal, या Lightning AI के CPU पर चला रहे हैं:
    1. Headless Execution: एजेंट कोड लिखने के बाद बैकग्राउंड में Godot को रन करेगा:

       godot --headless --path ./my_runner_game --script res://tests/run_autonomous_tests.gd

    2. सेल्फ-डीबगिंग लूप: यदि किसी स्क्रिप्ट में कं पाइल एरर या मिसिंग नोड रेफरेंस होगा, तो Godot का कं सोल आउटपुट तुरंत DeepSeek Harness को वापस मिलेगा। एजेंट
       खुद उस एरर को पढ़कर स्क्रिप्ट को सही करेगा।
    3. 3D रेंडरिंग बिना GPU के : यदि कभी विजुअल टेस्ट की आवश्यकता हो, तो लिनक्स सर्वर पर llvmpipe (Mesa Software Rasterizer) का उपयोग करके CPU पर ही
       सॉफ्टवेयर रेंडरिंग हो जाती है।

चरण 5: सिक्योरिटी और स्टोर रेडीनेस (Strix)
गेम तैयार होने के बाद:
    1. Strix सिक्योरिटी ऑडिट:

              Strix एजेंट पूरे कोडबेस और एक्सपोर्ट फाइलों को स्कै न करेगा।

              यह जाँचेगा कि सेव-फाइल में कोई Insecure Deserialization तो नहीं है, नेटवर्क रिक्वेस्ट्स (यदि लीडरबोर्ड है) सुरक्षित हैं या नहीं, और कोई हार्डकोडेड
              सेंसिटिव डेटा तो नहीं छू ट गया।
    2. Play Store पैके जिंग:

       godot --headless --export-release "Android" ./build/game_release.aab

def query_llm(system_prompt: str, user_prompt: str) -> str:
    headers = {
        "Authorization": f"Bearer {LLM_API_KEY}",
        "Content-Type": "application/json"
    }
    payload = {
        "model": MODEL_NAME,
        "messages": [
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": user_prompt}
        ],
        "temperature": 0.2
    }
    response = requests.post(f"{LLM_BASE_URL}/chat/completions", headers=headers, json=payload)
    return response.json()["choices"][0]["message"]["content"]

      अंदर धंस रहा है, टेक्सचर अजीब लग रहा है, या कै मरा दीवार के आर-पार जा रहा है।
