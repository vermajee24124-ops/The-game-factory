# DeerFlow 2.5 — Open-Source Monetization

Open source does not require the maintainer to give away every business service for free. The strongest model for DeerFlow 2.5 is to keep the core useful and open while charging for convenience, hosting, enterprise controls, or optional services.

## Practical revenue models

### 1. Managed hosted service

Offer DeerFlow 2.5 as a hosted service. Users pay for compute, storage, managed research runs, observability, backups and operations rather than for access to the source code itself.

### 2. Hosted team/enterprise edition

Keep the core runtime open source while offering paid team features such as organization management, SSO, audit controls, policy management, centralized billing, private deployments and premium support.

### 3. Paid support and implementation

Charge for installation, migration, custom MCP integration, performance tuning, security hardening, and architecture work.

### 4. Marketplace/services

Offer optional hosted connectors, managed browser/research infrastructure, model routing, artifact storage, or premium workflow templates. Make clear which pieces are third-party services.

### 5. Sponsorships

Use GitHub Sponsors and similar funding channels. GitHub Sponsors supports one-time and monthly tiers for eligible contributors, and personal-account sponsorships currently have no GitHub fee. See the official documentation for eligibility and payment details.

### 6. Commercial licensing only where permitted

Do not change or claim ownership of upstream licenses. A separate commercial license can only apply to code you own or to components whose licenses permit the chosen model.

## Recommended DeerFlow 2.5 model

Keep the core fork open source. Revenue can come from:

- managed hosting
- optional hosted research/search capacity
- team/enterprise operations
- premium support
- integration and consulting services
- optional managed storage/observability
- sponsorships

## Important distinction

Free source code, free API access and unlimited hosted inference are three different things. A project can be fully open source while its hosted APIs, GPU compute, search providers, or model inference remain metered or paid.
